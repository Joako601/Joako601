# Política de seguridad

Este repositorio contiene el perfil de GitHub y los scripts que lo mantienen actualizado. Solo se da soporte a la rama `main`.

Si encuentras una vulnerabilidad, repórtala de forma privada desde la pestaña **Security** del repositorio, con la opción **Report a vulnerability**. No abras un issue público.

Incluye qué archivo o workflow está afectado y cómo reproducir el problema.
